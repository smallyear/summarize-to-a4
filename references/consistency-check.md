# 一致性核对手册

疑点清单的判据（P0/P1/P2）和举证制在 SKILL.md 第 1 步。这里只讲**怎么查**。

底稿来自一份 110 页的交易所年报问询函回复（1,205 处数字、371 个日期）：
核出 7 处 P0、15 处 P1，另有 9 处一度像错、最终确认不是。下面每条都标了实测出处。

## 1. 先定核对深度

| 情形 | 做法 | 量级 |
|---|---|---|
| 短文（< 8000 字） | 通读时顺手核，不跑脚本 | 几分钟 |
| 长文 / 多来源 / 数字密集 | `a4 facts` 定位 + 本节勾稽 | 110 页约一轮通读 + 40 分钟 |
| 合同、法规原文、审计底稿 | 本 skill 不建议压缩，别在这里假装能审阅 | — |

`a4 facts` 只能抓「指标名被逐字重复而值不同」，实测 7 处 P0 里它只报出 1 处。
**别把核对工作外包给它**，它负责让你不用来回翻页。

## 2. 六类勾稽，按性价比排序

性价比的意思是：算起来便宜、命中率高。**先做 1、2 两行，能解决大半问题。**

| # | 检查项 | 怎么算 | 本次实测命中 |
|---|---|---|---|
| 1 | 合计 = 明细之和 | 逐行加总，与「合计/小计」比 | 预算 33,417+20,633+950=55,000 ✓ 干净；扣除项 1,664.62 ✓ 干净 |
| 2 | 分项 ÷ 总额 = 占比 | 占比对不上，通常是分子被换过 | 前五名 16,353.16÷34,740.99=47.07%，正文却写 47.68% → **P0** |
| 3 | 金额 ÷ 数量 = 单价 | 单价、单位成本都能倒推 | 28,526.54÷33,594=0.85 ✓；巡检 1,068.18÷65=16.43 ✓ |
| 4 | 毛利率 = 1 − 成本 ÷ 收入 | 与表列毛利率比 | 红外 1−21,952.55÷28,526.54=23.05% ✓；但「毛利 0.00」与「亏损合同」并存 → **P0** |
| 5 | 同比 = 本期 ÷ 上期 − 1 | 顺带验上期基数 | 应收周转 0.70 与 0.47 两个值，0.47 可由 34,741÷74,285 验出 → **P0** |
| 6 | 比例 × 总额 = 金额 | 尤其是履约进度 × 合同额 | 进度 58.93% × 合同 7,100 万 = 4,184 万，表列确认收入 1,912.32 万 → **P0** |

第 6 类最容易被放过：进度、覆盖率、计提比例这类"过程指标"往往和金额分列两处，
中间隔着几页，单看哪个都对。

## 3. 高发错误形态（按本次命中频次）

| 形态 | 本次实例 | 为什么难发现 |
|---|---|---|
| **数字转置** | 47.07 / 47.68｜27.66 / 27.27｜0.70 / 0.47 | 两个值都像真的，只有回到算式才知道谁是原值 |
| **期初期末串位** | 存货表写「期末 57,372.08」，同页合计 57,376.89，前者实为上一页的期初原值 | 标签错了，值本身是文档里另一个真值 |
| **口径切换不声明** | 销售毛利率 25.22（主营）/ 25.85（综合） | 两个都对，混用就错 |
| **结论与自己表格相反** | 「客户成立时间均在 2021 年及以前」vs 表里客户 12 成立 2024-12-31 | 结论在文末，表格在文初 |
| **单月归属与确认时点不符** | 127.98 万元报关日 2025/10/31，却计入 11 月；文中又声明「不存在跨期」 | 要同时看月度表、订单明细、确认政策三处 |
| **只列部分期间，合计却等于全年** | 分月产量只列 6 个月，加总恰为「全年 21,000 台」 | 加总对得上，反而像没问题 |
| **计提比例与文字判断相反** | 客户 18 计提 99.90%，同行写「回收风险相对较小」 | 一个在数字列，一个在文字列 |

## 4. 假阳性：先找一个能闭合的解释

**规则：能找到口径差、时点差、拆分差来解释，就不是疑点。** 找不到才算。

本次一度像错、最后确认无事的 9 类，全部属于这一条：

| 现象 | 闭合解释 |
|---|---|
| 账龄各档合计 13,056.44 ≠ 期末 12,772.10 | 表格提取串列，`284.35` 实为「期后回款」列合计（239.00+45.35 分毫不差） |
| 净利润 -23,076.27 万 vs 归母 -2.24 亿 | 合并净利润 vs 归母，差额为少数股东损益 |
| 净资产 12.84 亿 vs 归母净资产 13.14 亿 | 同上，少数股东权益为负 |
| 含税 -111.71 万 vs 不含税 -98.85 万 | ÷1.13 的增值税 |
| 研发人员薪酬占比 64.39% vs 工资及福利 64.20% | 前者含股份支付 0.19%，相加正好 |
| 同一科目「取得短期借款」6,420 / 7,234.26 | 一张表拆三项、一张并两项，差额 814.26 恰为票据贴现，两表小计都是 13,234.26 |
| 毛利率 25.22 与 25.85 并存 | 主营 vs 综合，两年同向，非笔误 |
| 3–4 年 50%、5 年以上 100%，个别客户却是 79.69% | 分档政策之上还有个别认定 |
| 1.10 亿 与 11,049.36 万 | 单位互写，正常 |

**表格类文档的第一嫌疑永远是「提取串列」，不是「原文写错」。** 报之前先看数字能不能对上别的列。

## 5. 流程性与时间线核对（监管文书特有）

这类错不影响数字，但会破坏"回复自洽"：

- **日期链**：收到函 → 回复 → 披露 → 复核日。本次「2026-05-07 查询顺丰官网」早于公告日、
  晚于问询日，顺序自洽。
- **成立日期 vs 合作起始年**：两者矛盾要么是笔误，要么是换了主体。
- **运输节点间隔**：报关→抵港 1–3 天是常态，某批显示"当日报关当日抵港"就该问一句；
  更要命的是**关键节点空缺（表里是「/」）而结论写「时间节点不存在逻辑矛盾」**。
- **文内引用编号**：问询函号、公告编号、审计报告号出现两处就要比对。

## 6. 落盘格式

`<name>.errata.md` 只放真疑点；**另设一张「已核对但确认不是矛盾」表**。

后者不是凑数——它防止下一轮（或换个人）重复劳动，也让人知道哪些地方已经看过。
本次 9 条假阳性全部留档，代价只有十几行。

每条真疑点的证据必须能同时引出**两处页码 + 原文短引**。引不出就不写，
宁可少报——用户手上未必有原文，一条编出来的矛盾他没法反驳，却会照着去改。

## 7. 之后怎么进 A4

| 级别 | 去处 |
|---|---|
| P0（改结论的数字/日期/口径） | 摘要里 `> !` 1–2 行点明 + errata 详列；**正文照抄原文值**，标 `〔原文前后不一致〕` |
| P1（结构断裂） | 只进 errata |
| P2（错别字、格式） | 不记 |

**绝不替原文改数。** 改了之后纸面更干净，但那是摘要替原文撒谎——用户拿这张纸去开会，
对不上就是事故。
